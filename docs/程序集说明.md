# 程序集说明（给 YooAsset + HybridCLR 用）

目标：主包尽量薄；**玩法 DLL + 配置 DLL + 配置 json** 都走 YooAsset 热更。

| 程序集 | 目录 | 是否热更 | 说明 |
|--------|------|----------|------|
| `JojoP.AOT` | `Assets/AOT` | 否（打进主包） | Bootstrap：闪屏/Loading、`ChannelId`、`JojoPGlobalSettings` |
| `JojoP.Config` | `Assets/Script/LubanCode`（`Gen/`） | **是** → `Bundle/Dll/JojoP.Config.dll.bytes` | Luban 表代码；引用 `Luban.Runtime`；**先加载** |
| `JojoP.HotUpdate` | `Assets/HotUpdate` | **是** → `Bundle/Dll/JojoP.HotUpdate.dll.bytes` | `GameApp`、兄弟团、广告、UI；引用 Config；**后加载** |
| `JojoP.Editor` | `Assets/Editor` | 仅编辑器 | Project Settings → JojoP、建场景、UIBind |

| 资源 | 目录 | 说明 |
|------|------|------|
| Luban data | `Bundle/LubanConfig` | json AB；日常数值热更 |
| 热更 DLL | `Bundle/Dll` | `*.dll.bytes`；随 Bundle 收集 |

加载顺序与细节见 [热更接入.md](热更接入.md)。

## 场景流程

1. `Assets/Scenes/Bootstrap.unity` → 只挂 `AppLauncher`（闪屏 → Loading 版本/渠道资源/HybridCLR）
2. 加载 `Assets/Scenes/Main.unity` → `GameApp`：隐私/配置/广告 → **主界面**
3. 主界面进我和我的龙兄南弟（2D 屏幕中割草）

## 以后怎么接

1. **YooAsset**：关 `devDirectPlay`，拉 `Bundle`（含 Dll + LubanConfig）  
2. **HybridCLR**：Hot Update Assemblies = `JojoP.Config` + `JojoP.HotUpdate`  
3. **上线**：去掉 AOT → HotUpdate 的 asmdef 引用，Loading 里按序 `Assembly.Load` `.bytes`
