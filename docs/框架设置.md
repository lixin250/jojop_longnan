# JojoP 框架设置（Project Settings）

统一入口：**Edit → Project Settings → JojoP**，或菜单 **JojoP → 打开框架设置**。

## 存哪儿

`Assets/Resources/JojoP/JojoPGlobalSettings.asset`  
运行时：`JojoPGlobalSettings.Load()`（Boot / 热更都能读）。

首次打开 Project Settings → JojoP 时会自动创建该资产。

## 现在管什么

| 区块 | 内容 |
|------|------|
| Boot | 默认渠道、YooAsset 包名、闪屏秒数、Main 场景名 |
| Host | CDN 主备、Worker 地址、各平台更新 URL、是否检查更新 |
| HybridCLR 镜像 | HotUpdate / AOT 程序集列表、主逻辑 DLL、`.bytes` 路径 |

点 **「从 HybridCLR Settings 同步」** 会把官方 `Project/HybridCLR Settings` 里的热更/AOT 列表拉到镜像区。  
**编译桥接 / Installer 仍用官方 HybridCLR Settings**，这里不替代。

## 以后怎么扩展

在 [`JojoPGlobalSettings.cs`](../unity/Assets/AOT/Settings/JojoPGlobalSettings.cs) 里加新的 `[Serializable]` 类字段，面板会用 `PropertyField` 自动画出来。例如：

- 隐私默认 URL、活动开关  
- 广告默认位 ID  
- 多渠道 CDN 表  

不必再东跳西跳各个零散 `.asset`（业务侧以本面板为主；插件官方设置除外）。
