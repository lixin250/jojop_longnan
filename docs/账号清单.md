## 1. Google Play Console（上架必须）

- [ ] 个人 Google 账号
- [ ] [Play Console](https://play.google.com/console) 注册 **个人** 开发者
- [ ] 交一次性 **$25**
- [ ] 按提示完成身份验证
- [ ] 创建应用，包名如 `com.jojop.stack`
- [ ] 建 **内部测试** 轨道，加测试 Gmail

- [ ] 填 **数据安全**（广告 SDK + 可选云存档）
