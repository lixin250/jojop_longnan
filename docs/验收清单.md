# 验收清单

先确认 Build Settings 含 `Bootstrap` + `Main`（或跑 **JojoP → 1. 生成场景和配置**）。

## A. Editor 冒烟

- [ ] 打开 `Assets/Scenes/Bootstrap.unity`
- [ ] Play：先闪屏 → Loading（有进度文案）→ 再进 Main
- [ ] 首次弹出隐私
- [ ] 同意后出现**主界面**（最高分 / **我和我的龙兄南弟** / 叠叠乐 / 设置），**没有**叠块
- [ ] 点「我和我的龙兄南弟」→ 大厅可见体力/培养点/章节；出征小学 → 自动割草 → **得胜**或**散旁**
- [ ] 散旁可重玩；得胜后三选一能招人；寒假/暑假休整能继续
- [ ] 大厅广告+体力/培养点、潜力加点生效（详见 `docs/我和我的龙兄南弟.md`）
- [ ] 点「叠叠乐」→ 出现叠块，点击落块
- [ ] 故意对不齐 → 结算：复活 / 双倍 / 再来一局 / **回主界面**
- [ ] Mock 激励复活能续上一局（每局一次）
- [ ] 双倍分生效
- [ ] 「回主界面」后块消失，可再点开始开新局
- [ ] 设置可打开隐私链接并关闭
- [ ] 多次再来一局会触发 Mock 插屏（看远程 `interstitialEveryNRetries`）

## B. Cloudflare

- [ ] `cd worker && npm install && npm run dev`
- [ ] `curl http://127.0.0.1:8787/health` 有 `ok`
- [ ] `curl http://127.0.0.1:8787/config` 有 `dailyRewardedCap`
- [ ] Unity `BackendConfig.baseUrl` = `http://127.0.0.1:8787`
- [ ] Console 出现「已应用远程配置」

## C. Windows 冒烟（本机可做）

当前编辑器若没装 Android 模块，先：

- [ ] **JojoP → 打 Windows 冒烟包**
- [ ] 跑 `Builds/Windows/JojoPStack.exe`：隐私 → 主界面 → 玩 → 结算 → 回主界面

## D. Android 内测（需 Hub 装 Android 模块）

- [ ] Hub → 安装 → 6000.4.0f1 → 添加模块 → **Android Build Support**
- [ ] 包名 `com.jojop.stack`
- [ ] **JojoP → 打 Android APK（开发包）** 或 AAB
- [ ] 上传 Play **内部测试**
- [ ] 真机：隐私同意 → 主界面 → 开始 → 测试广告
- [ ] 激励复活发奖；插屏按节奏出现
- [ ] 不用正式广告自点

## E. 正式上架前

- [ ] 隐私页换成真实主体名 / 邮箱
- [ ] AdMob 通过 + 收款资料
- [ ] 换成正式广告位 ID
- [ ] 数据安全表单填完
- [ ] 内部测 → 开放测 → 正式发布
