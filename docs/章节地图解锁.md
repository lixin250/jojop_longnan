# 章节地图解锁（龙南限定）

节奏约定：**一学期 ≈ 一次出征波节点**（上/下学期各 1；寒暑假休整不打）。  
小学 6×2、初中 3×2、高中 3×2；大学按学年；出社会按过年。

恶搞尺度：**熟人叙事 + 轻荒诞敌人**；景点可进图，但 **不毁文物、不辱先贤、不碰敏感公职实名**。围屋/太平桥/阳明线用「回乡打卡 / 导游团冲突 / 合影加塞」这类玩梗。

---

## 总览

| 章 | 年×学期 | 主集合地（Hub） | 打斗场景如何解锁 |
|----|---------|-----------------|------------------|
| 一·小学 | 6×2 | **龙翔广场** | 整章固定主图；小3+ 敌池加校霸 |
| 二·初中 | 3×2 | **龙南体育场** | 通关小学解锁章；学年内轮换 1～2 副图 |
| 三·高中 | 3×2 | 分校后「周末集合」 | 通关初中解锁；按年级开放夜场图 |
| 四·大学 | 3～4 学年 | 车站/围屋团聚 | 通关高中；学年+路线开景点/远征 |
| 出社会 | 过年×N | 夜场循环 | 通关大学；**职业线**开专属场景 |

竖切可先只跑小学；下表是 **内容规划**，表字段可后补。

## 一·小学（龙翔广场）

| 节点 | 地图 | 敌主题（递进） |
|------|------|----------------|
| 小1～2 上/下 | 龙翔广场 | 流浪狗、小团伙 |
| 小3～4 | 同左 | +校霸精英 |
| 小5～6 | 同左（可换天气/夜场皮） | 小团伙升级、期末「班主任幻影」轻量 |

**不做多地图**：小学生活动半径就该「广场反复横跳」，辨识度靠敌池与年级文案。

解锁下一章：小学 6 年暑假结算 → **初中**。

## 二·初中（3×2）

Hub：**龙南体育场**（打球冲突主叙事）。

| 年级 | 解锁打斗场景 | 叙事 |
|------|--------------|------|
| 初一 | **龙南体育场**（主） | 霸场、抢球 |
| 初二 | + **老城骑楼巷口**（黄道生/老街意向下的「巷口集合」） | 放学路过起哄、外校挑事预热 |
| 初三 | + **桃江边步道**（城北江边意） | 中考前焦虑怪、夜跑冲突 |

学期轮换：`ScenePool` 按 `GradeYear` 加权，不必每学期新图。

## 三·高中（3×2）

Hub 叙事：大家已分不同中学，**周末/假期才聚齐**。

| 年级 | 解锁打斗场景 | 叙事 |
|------|--------------|------|
| 高一 | **步行街夜市**、**网吧** | 校际摩擦、抢机 |
| 高二 | + **夜宵摊** | 醉汉、加塞、前任现任线预热 |
| 高三 | 上列全开；可选 **补习班走廊**（室内皮，非景点） | 年级主任幻影、压力怪 |

不在高中硬塞 4A 景区——那是「长大才能开车去」的东西，留给大学/社会。

---

## 四·大学（3～4 学年）

Hub：**车站 / 围屋团聚点**（回乡叙事）。

| 学年 | 解锁 | 说明 |
|------|------|------|
| 大一 | **车站广场**、**围屋前坪**（关西/燕翼「合影点」意向下） | 团聚线默认 |
| 大二 | + **阳明心谷·玉石仙岩外圈**（打卡道，不进洞毁刻） | 「游客加塞团」「研学喇叭怪」 |
| 大三 | + **太平桥观景台** / **杨村一带周末局** | 合影占位战、导游旗海 |
| 大四（若有） | + **虔心小镇 / 悦龙湾类「周末乐园」**（选 1） | 轻松波；或 **分校远征** 异地皮 |

双路线（已有预埋）：

- **团聚**：优先围屋/车站/景点打卡  
- **分校远征**：车站出发 + 抽象「外地食堂/宿舍楼下」（可不具名城市）

## 出社会（工作 / 考研 / 考公）

节奏：**无寒暑假，过年一年大波**；场景 = 「过年回龙南去哪闹」。

### 公共池（所有人过年可抽）

| 过年次数（示意） | 解锁场景 |
|------------------|----------|
| 第 1 年 | 夜宵摊、网吧 |
| 第 2 年 | + KTV |
| 第 3 年 | + 洗脚城 |
| 第 4 年+ | 公共池全开；景点「春节回乡打卡」复用大学景点皮 |

### 职业线专属（就业技解锁后挂池）

| 路线 | 专属打斗场景（恶搞） | 解锁条件 |
|------|----------------------|----------|
| 正常上班 | **工业园门口加班局**、**客户酒局包厢** | 上班第 1 个过年 |
| 考研硕/博 | **图书馆占座战场**、**答辩教室幻境** | 对应延迟年到达；博更晚、更难图 |
| 考公/编 | **政务大厅叫号龙**、**事业单位食堂窗口** | 考公延迟年到达；文案克制，不影射真人 |

机械×能源羁绊可在「工业园」图有环境加成（预埋）。

## 旅游景点：要不要、怎么恶搞

**要，而且很合适**——龙南辨识度靠围屋/阳明/太平桥，比通用夜场更「本地」。

| 建议进图 | 恶搞方式（安全） | 避免 |
|----------|------------------|------|
| 关西新围前坪 | 旅行团旗子海、自拍杆精英、黄牛「内部票」 | 拆围墙、砸文物 |
| 太平桥观景 | 占位合影、桥头「品字桥知识竞赛怪」 | 毁桥梗 |
| 阳明心谷/玉石仙岩外 | 研学喇叭、打卡不看路 | 戏弄王阳明本人、毁石刻 |
| 南武当 / 虔心小镇 | 周末亲子车流、乐园排队怪 | 宗教嘲讽 |

文案口吻：兄弟吐槽 + 地方自豪，不是糟蹋家乡。

## 推荐解锁手感（玩家视角）

```text
龙翔广场反复练手
  → 体育场打球冲突（初中）
  → 夜市/网吧（高中社交半径变大）
  → 车站回乡 + 围屋/景点打卡（大学有车有假）
  → 过年夜场 + 职业专属图（社会分化）
```

一句话：**地图跟着「人能去哪」解锁，景点放在大学以后，恶搞放在游客与生活气上，不碰文物与公职实名。**
