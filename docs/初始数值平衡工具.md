# 英雄初始数值平衡工具

## 数据原则

`人物&怪物.xlsx/RoleList` 是唯一权威数据源。Unity 编辑器窗口只保存调参草稿，
不创建第二份 ScriptableObject 数值。

完整链路：

`Unity 可视化调参 → Node 安全桥接 → 回写 Excel → Config MCP 校验 → Luban 导出 → Unity JSON`

Unity 菜单：`JojoP/数值平衡/英雄初始数值`。

- `从已导出配置重载`：读取当前 Luban JSON；未保存草稿会丢失。
- `保存到 Excel`：回写下列可调字段，不改姓名、描述、学历。
- `保存并导出 Luban`：回写后自动校验、导表并刷新 Unity。
- Excel/WPS 打开 `人物&怪物.xlsx` 时可能锁文件，先关掉再保存。

## 窗口里可以改什么

| 界面 | 回写字段 | 说明 |
|------|----------|------|
| 头像 | `avatar_loc` | 选中图片后写入**文件名（不含扩展名）** |
| 派系中文多选 | `faction_tags` | 互联网 / 创业 / 银行 / 烟草已拆开；界面中文，表内英文枚举，用 `\|` 连接 |
| 生命 / 攻击 / 移速 | `base_hp` / `base_atk` / `base_move` | 小学生阶段主预算 |
| 防御 | `base_defense` | 减伤 `100/(100+防御)`，100 防约减半 |
| 暴率% | `crit_rate` | 界面填百分数，表内存 0～0.75 |
| 暴伤× | `crit_damage` | 最低 1.0，暴击时伤害倍率 |
| 攻间 | `attack_interval` | 普攻间隔秒，越小越快 |
| 毕业技能多选 | `skill_ids` 中带 Job 的部分 | 从 SkillIndex 动态列出 |
| 校园/其他技能多选 | `skill_ids` 其余可装配部分 | 校园技、酒局口述技等；不含融合技/掉落技 |

## 高阶属性怎么参加

生命、攻击、移速 **仍然是开局主预算**。下面四项已经进入战斗，适合做职业特性，不要人人拉满：

| 属性 | 常用区间 | 参加方式 |
|------|----------|----------|
| 防御 | 0～20，按人定 | 直接减伤 |
| 暴击率 | 0～15% | 普攻掷点 |
| 暴伤 | 1.5 起步 | 仅暴击时生效 |
| 攻间 | 0.35～0.55 秒 | 普攻频率 |

**不要做成人物底板的属性：** 闪避、吸血、幸运、穿透。这些留给装备、局内 Buff、就业技，避免小学生数值膨胀。

硕博优势继续放在**毕业更晚 + 就业技倍率更高**，不要靠初始暴伤碾压。

预算指数只作观察色，不代替每人强度设计，也不给战斗定位。

## 调整纪律

- 开局按小学生阶段，行业 Tag 只影响相遇权重和毕业后就业技倾向。
- 同派系总预算可以有 ±10～15% 差异；每个人的强度和成长曲线单独定。
- 一次少调几个英雄，再跑固定波次对比。

1. `avatar_loc` 文件名（推荐）
