# 技能设计约束（我和我的龙兄南弟）

与项目 skill `longnan-brothers-design` 同步；切换对话后以本文 + skill 为准。

## 1. 硕 / 博：晚毕业，就业技更值钱

- 局内成长到出社会后，按「过年次数」计延迟：硕 2～3（默 2）、博 **5**、考公/编 1～3（默 2）、正常上班第 1 年。
- **未毕业**：只有校园技 / 补偿盾；**不可**放出完整就业技。
- **毕业解锁**：就业技生效；硕/博档位数值与覆盖面 **高于** 同学历「正常上班」同职技能（「更值钱」）。
- 已实现：`EducationProgram.job_delay_years / graduation_skill_mul` 与
  `LifeRouteGrowth.wait_default_years` 共同决定解锁；技能表 `show_tags` 含 `Job` 的技能在毕业前不会装配。
- 硕默认 `1.30`、博默认 `1.55` 毕业技倍率；后续局内升级再叠加 `JobSkillLv`，不白送一级。

## 2. 基础数值与局内平衡（怎么把握）

每人强度和成长曲线由策划在 Unity `JojoP/数值平衡/英雄初始数值` 里定。
窗口只给预算观察色，**不给**坦克/输出/辅助定位建议。
数值策划的工作是把每个人做成可读的强度与毕业节奏，不是替战斗程序填模板。

**把握原则：**

1. 同派系允许 ±10～15% 差异，用技能特性区分，不靠开局表碾压。  
2. 强度主要来自 **波间三选一升级** 与 **就业技解锁节奏**。  
3. 精英战靠破甲/易伤/减速克制高防怪；群怪战靠 AoE/召唤。这些是技能设计，不是底板定位。  
4. 英雄人物卡：中文派系（互联网 / 创业 / 银行 / 烟草已拆开）、毕业技/校园技多选、
   头像预览，以及生命/攻击/移速/防御/暴率/暴伤/攻间。保存回写 Excel 后再导出 Luban。
   闪避、吸血、幸运不进人物底板。详见 `初始数值平衡工具.md`。

竖切验收锚点：小学前段单人可带伤得胜；满编后靠搭配而非单人无脑清图。

## 3. 同职相似 + 特性；跨职搭配

- **同职**：技能「骨架」可像（都有砸、都有奶），但触发条件/目标/副效果必须不同。  
- **跨职**：用 `faction_tags` 做羁绊，不绑死姓名。典型：**Mechanical × Energy**（谢博 × 物资哥）。

示例（详表见 `人物刻画与羁绊.md`）：

- 土木：鱼固「工地砸」AoE vs 万总「项目审批」点名易伤 vs 军军「三方巡检」区域坦辅  
- 互联网：猩哥「搏一把/肝帝」 vs 阿允「告料」点名冲锋 +「算力过载」（硕更值钱）  
- 烟草 / 银行：红双喜核算红利 vs 含固融通资金，不再共用一个财会 Tag  
- 创业：赖镇拉人开工 vs 龙头扭亏为盈，不跟互联网混在一起  
- 机械×能源：拆装/扭矩 + 能源增幅/供电 → 重装过载羁绊候选
- 能源：欧版高中后早成型 vs 物资硕士晚解锁高倍率储能辅助
