## 1. Luban 表

| 表 | input | 说明 |
|----|------|------|
| `TbRoleList` | `RoleList@人物&怪物.xlsx` | 角色；`skill_ids` 为 **string** 列表 |
| `TbSkillIndex` | `SkillIndex@技能.xlsx` | 技能；`id`/`owner_id`/`effect_ids` 均为 **string** |
| `TbSkillEffect` | `SkillEffect@技能.xlsx` | 效果；`id` 为 **string** |
| `TbFusionSkill` | `FusionSkill@技能.xlsx` | 派系羁绊 → 授予融合技 id |

```text
RoleList.skill_ids[]          →  SkillIndex.id          (string)
SkillIndex.effect_ids[]       →  SkillEffect.id         (string)
FusionSkill.grant_skill_id    →  SkillIndex.id
SkillIndex.owner_id           →  RoleList.id 或 campus/mow/fusion
```

命名：`{归属}_{动作}`，如 `xiebo_dismantle`、`cs_lixin_gamble`、`campus_courage`。

改表后：`config/Config/gen导表.bat`。  
**不要**跑已删除的整表覆盖脚本。分段注释首列只能是精确 `##`。
