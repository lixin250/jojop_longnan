## 已落地的教育 / 就业字段

- `RoleList.education_level`：最终学历/培养类型（含中专、职高、专科、本硕博）
- `RoleList.life_route`：直接就业、继续升学、考公编、创业、灵活就业
- `RoleList.career_sector`：士农工商成长模板
- `EducationProgram`：学制、就业技延迟、毕业技倍率
- `LifeRouteGrowth`：等待年限与等待期补偿
- `CareerGrowth`：就业后血/攻/移速/CD/资源倾向

运行时由 `RoleCatalog` 读取这些表，`Academic` / `Official` 仅保留为细分融合标签，
不再代替学历或人生路线。
