# 广告接入（AdMob）

默认 **Mock** 假广告，能完整测复活 / 双倍 / 插屏流程。

## 接真 AdMob

1. Package Manager 安装 Google Mobile Ads for Unity  
2. Android Player Settings 配好 App ID（插件设置里也会要）  
3. Scripting Define Symbols 增加：`JOJOP_HAS_ADMOB`  
4. `AdsConfig` 里 Provider 选 **AdMob**  
5. 内测通过前继续用测试 ID；**禁止自点击正式广告**
