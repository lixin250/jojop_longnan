# 热更接入（YooAsset + HybridCLR）

纯 **IAA（只看广告）** 不用接内购订单；热更只服务「扩内容、修 Bug、调广告配置资源」。

## 已写入工程的包（`Packages/manifest.json`）

| 包 | 版本/来源 |
|----|-----------|
| HybridCLR | git `focus-creative-games/hybridclr_unity` |
| YooAsset | openupm `3.0.5` |
| UniTask | git Cysharp/UniTask |
| Scriptable Build Pipeline | `1.21.25` |
| Luban Runtime | git `focus-creative-games/luban_unity` |

Unity 打开工程后会拉包。若 Git URL 失败：检查 git、代理，或改用 Gitee 镜像。

## 第一次打开必做

1. 等 Package Manager 装完，Console 无红字  
2. 菜单 **HybridCLR → Installer… → Install**（装原生支持，只需一次）  
3. **HybridCLR → Settings**：Hot Update Assemblies 含 **`JojoP.Config`**、**`JojoP.HotUpdate`**（工程已写入）  
4. **Edit → Project Settings → JojoP**：点「同步」拉齐镜像；确认 DLL.bytes 目录为 `Assets/Bundle/Dll`  
5. 日常开发：Play **Bootstrap**，`AppLauncher` 勾选 **devDirectPlay**（Loading 走短桩）→ 闪屏 → Loading → Main  

框架总设置说明见 [框架设置.md](框架设置.md)。

## 程序集分工（别改乱）

| 程序集 | 热更？ | 内容 |
|--------|--------|------|
| `JojoP.AOT` | 否 | 闪屏/Loading、`ChannelId`、YooAsset/HybridCLR 启动管线、切 Main |
| `JojoP.Config` | **是** → `Bundle/Dll/JojoP.Config.dll.bytes` | Luban 生成表代码（`Script/LubanCode/Gen`） |
| `JojoP.HotUpdate` | **是** → `Bundle/Dll/JojoP.HotUpdate.dll.bytes` | `GameApp`、兄弟团、广告、UI；依赖 Config |
| `JojoP.Editor` | 仅编辑器 | 菜单、UIBinder 自动收集 |

上线热更时：去掉 AOT → HotUpdate 的 asmdef 引用，改运行时 `Assembly.Load`。

### Loading 加载顺序（正式包）

```text
Yoo 差量完成
  → AOT 元数据补充
  → Load JojoP.Config.dll.bytes      （先）
  → Load JojoP.HotUpdate.dll.bytes   （后）
  → 加载 Bundle/LubanConfig/*.json → new JojoP.Cfg.Tables(...)
  → 反射创建 GameApp
```

开发 `devDirectPlay`：DLL 仍在编辑器主域，可不放 `.bytes`。

## Luban：源码 / data / DLL.bytes

```text
Excel → gen.bat
         ├─ Script/LubanCode/Gen     （C# 源，进 JojoP.Config 程序集）
         └─ Bundle/LubanConfig       （json，Yoo AB）

HybridCLR CompileDll
         └─ 拷贝 → Bundle/Dll/JojoP.Config.dll.bytes
                   Bundle/Dll/JojoP.HotUpdate.dll.bytes
```

| 变更 | 更什么 |
|------|--------|
| 只改 Excel 数值 | 只更 `Bundle/LubanConfig`（json AB） |
| 加字段/加表 | gen → 编 Config.dll → 更新 `.dll.bytes` + json |
| 改玩法逻辑 | 编 HotUpdate.dll → 更新 `.dll.bytes` |

## 启动链路（Bootstrap → Main）

```text
AppLauncher
  ├─ 闪屏 Splash（品牌，不下载）
  ├─ Loading
  │    1. HostPlayMode：对比 本地清单 vs 远端 DefaultPackage.version
  │    2. 差量下载（进度条：文件数 / 体积 / 百分比）
  │    3. HybridCLR DLL.bytes + LubanConfig（Yoo 已对齐后再进 Main）
  └─ LoadScene(Main) → GameApp
```

开发：Bootstrap 勾选 **devDirectPlay**，Loading 走短桩，不打 CDN。  
出包：菜单 **JojoP → 构建与热更**，关掉开发直开。

### 构建并推 R2

热更文件 **直传 Cloudflare R2**，不经过 `worker/`（Worker 以后写 `/config` `/save` 等游戏接口）。

1. Dashboard → R2 → **Manage R2 API Tokens** 建 Access Key，填到 Unity 构建窗口（只存在 EditorPrefs）
2. **JojoP → 构建与热更**
   - 客户端 CDN：`Local`（只用 StreamingAssets）或 `CloudflareR2`（Loading 去公开 URL 拉差量）
   - 编译热更 DLL → 构建 YooAsset → 增量上传 R2
3. 关 `devDirectPlay` 且选 `CloudflareR2` 后，Loading 显示本地版本 → 远端版本并下载

公开根（已开 r2.dev）：`https://pub-781168dca86c49c3826ace7d12450b5a.r2.dev/{channel}/{Android|StandaloneWindows64}/`

- 渠道：`ChannelId`（`AppLauncher.channelOverride` 或打包宏 `JOJOP_CHANNEL_*`）
- **玩家交互**：只在 Main 之后；Loading 不做开始/活动

## 配置 / UI 商业路径

选型对比与定案见 **[热更配置与UI选型.md](./热更配置与UI选型.md)**。

- 表数据：`CfgTables`（Yoo → Editor 文件兜底）→ `new JojoP.Cfg.Tables`  
- UI：UGUI Prefab + `UIBinder` / UIBind；薄 `UiPanelService` 从 Yoo 打开面板  

## UIBind 怎么用

1. 面板根节点挂 `UIBinder`  
2. Prefab 里用 key 绑按钮/文本（或右键 **自动收集子节点**）  
3. 代码：`binder.Get<Button>("btn_revive")`  

以后 UI Prefab 进 YooAsset，热更只更 Prefab+脚本，不改 AOT。

## 下一步扩游戏建议顺序

1. 日常开发保持 `devDirectPlay`
2. 要验热更：关直开 → **JojoP → 构建与热更** 打 Yoo 并上传 R2 → Loading 看版本对比
3. APK 首包建议写入 StreamingAssets，之后只推 R2 差量

不要一上来关直开硬跑完整热更链，容易卡在清单路径。
