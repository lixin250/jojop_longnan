## 波间肉鸽

波后三选一来自 `局内成长.xlsx/RogueReward`：属性、恢复、校园/就业技、
临时技能、攻击核心、人物相遇、龙南事件。  
人物不会一次选择直接入队：按 `CharacterEncounter` 增加个人好感，默认 3 次满；
槽位已满时保留“已结识”，扩编后自动集合。  

`TimelineEvent` 是波次间的城市/游戏时间点，不是地方志。`anchor_year` 只是玩笑锚点，
局内按 `chapter_id + sequence` 推进；它不会越过毕业规则提前解锁就业技。
`boost_tags / encounter_weight_mul` 提高相关行业兄弟的相遇概率，
`event_ids` 把当期节点丢进波间事件池。一律标 `Oral / Creative`、`verified=false`，
不冒充县志史实。
每个奖励页可看广告刷新一次（排除旧选项、不加稀有度）。
假期：养伤推进 + 可选广告培养点  

上阵位由 `RunChapterRule` 配置：小学默认 3，广告每局最多扩 2 位；`-1` 表示不限人数。
超过 3 人主要增加怪量、刷新密度和少量精英率，不等比抬高敌人血攻。

攻击核心是团队唯一槽：普通 / 贯穿 / 连锁 / 溅射，获得新核心会替换旧核心。
每人另有 1 个 `loot_*` 临时技能槽，不覆盖真人固有校园技和就业技。

## 初始数值（竖切向）

- 开局「我」约 **110 血 / 14 攻**；杂兵脆、攻速慢；小学小1～2 第一波约 **4** 只、刷怪间隔偏慢  
- 校霸精英从 **小3** 才进池；得胜后存活兄弟回 **35%** 血  
- 目标：单人能打过小学前段，靠招人/养成往上爬  

## 验收要点

1. 主界面进兄弟团大厅，可见章节锁与局外资源  
2. 小学出征：割草自动战 → 得胜 / 散旁  
3. 散旁可重玩；局外培养点不回档  
4. 得胜后三选一能累积人物好感、替换技能/装备；寒假/暑假休整能养伤  
5. 广告按钮在 Mock/远程关广告时可刷新奖励或将小学上阵位从 3 扩到 5  
6. 潜力加点后下一局更肉  
7. 小学第一波单人不应秒散旁（可带伤得胜）
