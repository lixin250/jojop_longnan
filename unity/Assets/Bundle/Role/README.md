# Role 资源

规划见仓库根目录 `docs/角色资源与Luban.md`。  
概念图裁切与覆盖导入见仓库 `art/README.md`。

当前可直接把大头贴放到 `Assets/Bundle/Role/大头贴/`，文件名对齐表字段 `avatar_loc`。

| 子目录 | 用途 | 命名例 |
|--------|------|--------|
| `大头贴/` | 档案/HUD `avatar_loc` | `role_oban_avatar.png` |
| `battle/` | 战场 `battle_loc` | `role_oban_battle.png` |
| `halfbody/` | 形态半身像 | `role_oban_half_worker.png` |
| `poster/` | 海报/Banner | `role_oban_poster.png` |

另：`Bundle/Skill/icon/`、`Bundle/Item/icon/`。

Unity 菜单：`JojoP/Art/从 art/_final 覆盖导入 Bundle`。

完整头像文件名清单见仓库 `docs/初始数值平衡工具.md`。
